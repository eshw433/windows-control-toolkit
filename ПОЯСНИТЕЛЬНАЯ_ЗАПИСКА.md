## 1. Введение и актуальность

Я занимаюсь программированием с 13 лет,на курсы я хожу с 14. Сначала это были простые скрипты на Python, потом я начал углубляться в системное программирование, разбираться, как работает Windows изнутри, и понял, что большинство утилит для мониторинга системы либо перегружены рекламой, либо отправляют данные в облако. Я решил создать свой инструмент, который будет полностью локальным, приватным и функциональным.

**Windows Control Toolkit (WCT)** — это настольное приложение для Windows, которое объединяет два важных направления:
1. **Сетевой мониторинг и контроль** — кто и куда ходит из установленных программ, с возможностью блокировки через Windows Firewall.
2. **Умный организатор файлов** — автоматическая сортировка, поиск дубликатов, карантин и анализ «пожирателей диска».

Проект актуален, потому что пользователи ежедневно сталкиваются с нежелательными сетевыми соединениями и беспорядком в папке «Загрузки», а существующие решения либо слишком сложные, либо платные.

## 2. Цель и задачи

**Цель:** создать удобное, красивое и полностью автономное приложение для контроля сетевой активности и управления файлами на Windows.

**Задачи:**
- Разработать модуль мониторинга TCP/UDP-соединений в реальном времени.
- Реализовать интеграцию с Windows Firewall для создания правил блокировки.
- Создать сканер и правила для автоматической организации файлов.
- Реализовать поиск дубликатов по SHA-256 и карантин файлов.
- Добавить диспетчер задач, инспектор процессов, планировщик и онбординг.
- Добавить менеджер автозагрузки, USB-монитор, поиск по содержимому файлов и авто-обновление.
- Обеспечить локальное хранение всех данных без облачной телеметрии.
- Написать тесты и подготовить приложение к сборке в единый `.exe`.

## 3. Технологии и библиотеки

Я выбрал стек, который позволяет быстро разрабатывать кросс-платформенный код, но при этом глубоко интегрироваться в Windows.

| Библиотека | Назначение | Почему выбрал |
|---|---|---|

| **watchdog** | Мониторинг файловой системы | Реальное время: отслеживает появление новых файлов в папке «Загрузки» |
| **pydantic** | Модели настроек | Валидация конфигурации, типизация, читаемость кода |
| **loguru** | Логирование | Ротация логов, цветной вывод, простая настройка. Логи хранятся локально 14 дней |
| **reportlab** | PDF-экспорт | Для генерации отчётов в PDF из UI, fallback на текст если библиотека не установлена |
| **PyInstaller** | Сборка в `.exe` | Один файл — пользователю не нужно устанавливать Python |
| **pytest + pytest-qt** | Тестирование | Проверка логики модулей и корректности работы Qt-виджетов |

## 4. Архитектура проекта

Приложение построено по модульному принципу. Я разделил код на 5 слоёв:

1. **UI (`ui/`)** — 23 страницы, виджеты, темы, палитра команд (Ctrl+K). Все страницы используют единый стиль на основе QSS.
2. **Core (`core/`)** — инфраструктура: event bus, scheduler, i18n (3 языка), команды, шорткаты, трей, updater, экспорт.
3. **Modules (`modules/`)** — бизнес-логика:
   - `network/`: monitor, firewall_adapter, bandwidth, GeoIP, DNS-cache, risk scorer
   - `files/`: scanner, rule_engine, dedupe, size_analyzer, templates, content_search
   - `system/`: startup_manager, usb_monitor
4. **Database (`db/`)** — SQLite с 20 таблицами, миграциями, WAL, 9 репозиториями CRUD.
5. **Shared (`shared/`)** — общие модели, enums, dataclasses.

Связь между слоями идёт через `app.py` — центральный Application-объект, который держит все сервисы и репозитории.

## 5. Что я реализовал

### Сетевой модуль
- Живой мониторинг всех TCP/UDP соединений с разрешением доменов (DNS-кэш).
- GeoIP-определение страны по IP.
- Risk-scorer: автоматическая оценка риска соединения по порту, пути exe, подписи, издателю.
- Центр доверия: allow / block для процессов.
- Интеграция с Windows Firewall через `netsh` — создание правил с префиксом `WCT_`.
- Трекер трафика: входящий/исходящий по приложениям за день.

### Файловый модуль
- Сканер папки «Загрузки» с предпросмотром плана организации.
- 16 встроенных шаблонов правил (PDF → Documents, EXE → Installers и т.д.).
- Дедупликация: двухшаговый хэш (быстрый + SHA-256), удаление с выбором стратегии.
- Карантин: безопасное перемещение файлов, восстановление, удаление по горячим клавишам (Del / R).
- Disk Hogs: анализ самых больших, старых и пустых файлов.
- Поиск по содержимому файлов: полнотекстовый поиск в TXT, PDF, DOCX с превью и номерами строк.
- Полный журнал действий с фильтрами и откатом (rollback).

### Системные и UI-функции
- **6 тем** (midnight, aurora, solar, amethyst, graphite, light) на основе единой палитры из 14 переменных.
- **Командная палитра Ctrl+K** — 35+ команд, fuzzy-поиск, история.
- **Диспетчер задач** и **Инспектор процессов** — фоновые QThread, sparkline-графики CPU/RAM.
- **Welcome Screen** — 4-шаговый онбординг при первом запуске.
- **Планировщик** — управление периодическими задачами из UI.
- **Менеджер автозагрузки** — сканирование реестра (HKCU/HKLM Run, RunOnce) и папок Startup, включение/отключение/удаление записей.
- **USB-монитор** — обнаружение подключённых USB-накопителей через WMI и psutil.
- **Авто-обновление** — проверка релизов на GitHub, просмотр release notes, открытие страницы загрузки.
- **PDF-экспорт**, экспорт CSV/JSON, резервное копирование БД.
- **Системный трей**, автозапуск, тихие часы.
- **i18n** — 440+ ключей, 3 языка (EN, RU, AZ).

## 8. Заключение

Этот проект научил меня проектировать архитектуру реальных приложений, работать с потоками (QThread), интегрироваться с ОС на уровне процессов и сети, и писать тестируемый код.
