# Code of Conduct

## Our Standards

This project welcomes contributors and users from all backgrounds. We expect:

- **Respectful communication** — no harassment, discrimination, or trolling
- **Constructive feedback** — focus on ideas, not people
- **Patience with beginners** — everyone starts somewhere
- **Clear bug reports** — include reproduction steps and system info

## Scope

This code applies to:
- GitHub issues, pull requests, and discussions
- Project documentation and comments
- Any project-related communication

## Enforcement

Violations may result in:
1. Warning
2. Temporary ban from interactions
3. Permanent ban for severe or repeated violations
